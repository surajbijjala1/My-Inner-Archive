# Lock-scene images

Used by `components/DiaryScene.tsx` (the lock screen and landing page) and,
for the wood, by the desk the open book lies on. Built by
`scripts/build-scene-assets.py`.

| File | What it is | Size | Source | Licence |
|---|---|---|---|---|
| `cover.webp` | the book's cover, top-down (640 × 858, alpha) | 145 KB | `References/cover-clean.png`, supplied by the project owner | **not recorded: confirm before release** |
| `lamp.webp` | the banker's lamp (428 × 720, alpha) | 55 KB | `References/lamp.png`, supplied by the project owner | **not recorded: confirm before release** |
| `clasp.webp` | the brass swing-latch clasp (260 × 226, alpha) | 24 KB | `References/clasp.png`, supplied by the project owner | **not recorded: confirm before release** |
| `wood-dark.webp` | desk, dark theme (768 px tile) | 9 KB | generated by the build script from noise | none needed |
| `wood-light.webp` | desk, light theme (768 px tile) | 13 KB | generated by the build script from noise | none needed |

The three photographs arrived with transparent backgrounds; the script only
pulls the matte in by a pixel or two (to lose a pale fringe), crops, resizes
and re-encodes. `book-angled.png` and `desk-scene.png` in the references
folder were used as references for thickness and lighting only; nothing from
them ships.

Only the wood for the active theme is fetched (it is a CSS token), and the
photographs are fetched when the scene is first drawn, under the ink line.
